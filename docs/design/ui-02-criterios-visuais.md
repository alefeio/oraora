# UI-02 — Critérios visuais da exploração A+B

Critérios para avaliar AB-1, AB-2 e qualquer híbrido futuro.  
Não substituem regras de produto.

## Marca

1. Logomarca oficial (`logo.png`) sem redesenho, recoloração ou tipografia substituta.
2. Assinatura e essência podem ser tipográficas; não competir com o wordmark do arquivo.
3. Símbolo de infinito = conexão/eternidade; iconografia linear só como apoio.

## Cor e contraste (WCAG 2.2 AA)

| Uso | Permitido | Proibido |
|---|---|---|
| Texto normal | `#2A2140`, `#5B5270`, `#533E7E`, muted ≥4,5:1 | Gold/coral/sage como texto |
| Texto em primary | Cream `#FCF7EE` | Cinza claro |
| Acentos | Superfície, underline, glow, ícone | Parágrafo/label pequeno |
| Fundos | Cream, white, soft cream | Gradientes excessivos |

Meta de muted na exploração: `#534A66` (substitui `#7A718C` do produto atual).

## Tipografia

- Display: **Nunito** 600–800  
- UI/corpo: **Inter** 400–600  
- Escala clara: display / title / body / meta  
- Line-length de leitura ≈ 60–72ch  

## Composição A+B

- Espaço generoso; uma intenção por seção.
- Cards **somente** quando agregam interação ou agrupamento necessário.
- Auth e leitura: ambientação sem poluição.
- Mobile-first na avaliação (mesmo com demos desktop).

## Componentes (exploração)

- Botões ≥44px de altura; primary/secondary/ghost/disabled distintos.
- Focus-visible sempre visível.
- Erro/sucesso com texto + cor (nunca só cor).
- Nav: destinos atuais apenas; estado ativo visível.

## Tom visual

Transmitir: fé, acolhimento, esperança, humanidade, confiança, sofisticação, simplicidade, modernidade.  
Evitar: painel admin, excesso de bordas, infantilização, clichês religiosos, template genérico, animação distrativa.

## Aceite desta etapa (UI-02)

O proprietário aprova **uma variação ou proporção** para seguir ao UI-03.  
Style tiles **não** são layouts finais.
